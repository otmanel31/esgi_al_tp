# Application Monolithique IoT - Gestion de Capteurs

## 📋 Description

Cette application monolithique gère un système IoT de capteurs connectés. Elle simule :
- La réception de données depuis un broker de messages (simulé)
- Le stockage des informations capteurs et de leurs données
- Une API REST pour consulter les données
- Une API REST pour envoyer des commandes aux capteurs
